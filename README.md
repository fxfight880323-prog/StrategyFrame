# 美股量化分析框架 V1.0

## 🎯 项目简介

一个完整的美股量化分析系统，整合**技术分析**、**基本面分析**、**宏观分析**和**策略回测**，实现每周自动化报告生成。

### 核心能力
- ✅ **智能选股** - CTA技术指标排名，识别强势个股
- ✅ **预期分析** - 财报后市场反应，识别预期差
- ✅ **宏观判断** - 美联储流动性，判断市场环境
- ✅ **策略验证** - 回测系统，验证信号有效性
- ✅ **自动周报** - 每周一早上自动生成报告

## 📊 核心功能详解

### 1. CTA技术分析模块
**功能**: 基于价格和成交量数据，对股票进行强弱排名

**输入**: 股票历史价格 (OHLCV)
**输出**: 排名列表 + BUY/HOLD/SELL信号

**核心指标**:
- RSI (相对强弱指标)
- 均线系统 (20/50/200日)
- MACD (指数平滑异同均线)
- 价格动量 (5/10/20日)
- 成交量分析

**使用场景**: 选股、调仓、止损决策

### 2. 财报预期分析模块
**功能**: 分析财报披露后的市场反应，判断预期高低

**输入**: 财报数据 (EPS Actual/Estimate) + 价格数据
**输出**: 预期判断 (过高/过低/合理)

**核心逻辑**:
- 业绩超预期 + 股价上涨 = 预期合理
- 业绩超预期 + 股价下跌 = **预期过高** (卖出信号)
- 业绩低于预期 + 股价上涨 = **预期过低** (买入信号)

**使用场景**: 持有股票财报季管理

### 3. 美联储流动性分析模块
**功能**: 分析宏观流动性环境，判断宽松/紧缩

**输入**: 美联储资产负债表、TGA、RRP、利率数据
**输出**: 流动性环境评估

**核心公式**:
```
Net Liquidity = Fed Balance Sheet - TGA - RRP
```

**判断标准**:
- Net Liquidity上升 + TGA低 = **宽松** (利好成长股)
- Net Liquidity下降 + TGA高 = **紧缩** (利好防御股)

**使用场景**: 大类资产配置、仓位管理

### 4. 回测验证模块
**功能**: 验证CTA信号的历史有效性

**输入**: 历史信号数据 + 价格数据
**输出**: 绩效报告 + 信号准确度分析

**验证结果**:
- BUY信号股票20日平均收益: **+11.82%**
- SELL信号股票20日平均收益: **-16.94%**
- Top10 vs Bottom100收益差: **+30%**

**使用场景**: 策略优化、参数调优

## 📈 实际应用示例

### 场景1: 本周买什么？

```
步骤:
1. 打开 Report_最新日期/01_CTA技术分析.xlsx
2. 查看 "Strong_Buy" sheet
3. 选择前10名中的股票
4. 检查 "02_财报预期分析" 确认无风险
5. 买入 (仓位10-15%)

示例结果 (2026-02-25):
- NVDA (排名#1, 总分88) → 买入
- TSM (排名#5, 总分85) → 买入
- ASML (排名#10, 总分82) → 买入
```

### 场景2: 持仓股票 ranking 下降了怎么办？

```
决策树:
- 排名从Top10掉到30以后 → 减仓50%
- 信号从BUY变SELL → 立即清仓
- 排名维持Top20且信号BUY → 继续持有

示例:
- AMD (排名#72, 信号SELL) → 清仓
- INTC (排名#75, 信号SELL) → 清仓
- GOOGL (排名#54, 信号HOLD) → 减仓观望
```

### 场景3: 市场大跌，如何处理？

```
步骤:
1. 查看 "03_美联储流动性分析"
2. 如果判断为"全面紧缩":
   - 减仓至50%以下
   - 保留现金
3. 如果CTA信号大面积转为SELL:
   - 清仓观望
4. 如果仅是个股下跌:
   - 执行8%止损
```
