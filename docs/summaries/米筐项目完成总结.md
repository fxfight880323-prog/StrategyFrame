## 🏗️ 架构设计

```
RiceQuantDataProvider (数据层)
├── get_stock_price()      # A股/港股/美股
├── get_future_price()     # 期货数据
├── get_option_chain()     # 期权链
├── get_index_components() # 指数成分股
└── get_factor_data()      # 因子数据

CTADataAdapterRQ (CTA适配器)
└── get_cta_data()         # CTA分析数据

FLPDataAdapterRQ (FLP适配器)
├── get_50etf_options()    # 50ETF期权
└── get_300etf_options()   # 300ETF期权

CTARiceQuantEngine (CTA引擎)
├── analyze_symbol()       # 单标的分析
└── run_analysis()         # 批量分析

FLPRiceQuantEngine (FLP引擎)
├── get_next_expiry()      # 获取到期日
├── select_put_option()    # 选择Put期权
└── execute_hedge()        # 执行对冲

IntegratedRiceQuantStrategy (整合策略)
└── run()                  # 完整运行
```

## 🎯 核心功能

### 1. 数据获取

| 数据类型 | 支持情况 | 代码示例 |
|----------|----------|----------|
| A股日线 | ✅ 完整 | `000001.XSHE` |
| 期货数据 | ✅ 完整 | `IF2403` |
| 期权数据 | ✅ 完整 | `510050.XSHG` |
| 指数成分 | ✅ 完整 | `000300.XSHG` |
| 财务因子 | ✅ 完整 | `get_factor()` |

### 2. CTA趋势分析

**分析标的** (A股核心资产):
- 平安银行 (000001.XSHE)
- 万科A (000002.XSHE)
- 美的集团 (000333.XSHE)
- 五粮液 (000858.XSHE)
- 海康威视 (002415.XSHE)
- 宁德时代 (300750.XSHE)
- 浦发银行 (600000.XSHG)
- 贵州茅台 (600519.XSHG)
- 中国平安 (601318.XSHG)
- 中国中免 (601888.XSHG)

**信号生成**:
- 20日/60日均线交叉
- ATR通道突破确认
- 评分系统 (0-100分)

### 3. FLP期权对冲

**对冲工具**: 50ETF期权 (510050.XSHG)

**执行规则**:
- 每月第四个周三到期
- Delta目标: -0.07 ~ -0.10
- 轻度虚值 Put
- 预算: 组合价值的5%

## 🚀 使用方式

### 第一步: 安装SDK

```bash
python install_rqdatac.py
```

或手动:
```bash
pip install rqdatac
```

### 第二步: 运行策略

```bash
python CTA_FLP_RiceQuant.py
```

### 第三步: 查看结果

```bash
# CTA信号
cat cta_ricequant_signals.csv

# 查看图表 (如果已集成可视化)
start Report_*/charts/*.png
```

## 📊 与AKShare版本对比

| 维度 | 米筐版本 | AKShare版本 |
|------|----------|-------------|
| **数据源** | 米筐专业数据 | AKShare免费数据 |
| **A股数据** | ✅ 实时 | ⚠️ 延迟1天 |
| **期货数据** | ✅ 完整 | ⚠️ 有限 |
| **期权数据** | ✅ 真实 Greeks | ❌ 模拟估算 |
| **使用成本** | 需要订阅 | 完全免费 |
| **适合场景** | 专业交易 | 学习研究 |

**推荐**:
- 实盘交易: 米筐版本
- 回测研究: AKShare版本
- 两者互补使用

## 💡 三种数据方案对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **AKShare** | 免费、国内稳定、易用 | 数据有延迟、无期权 | 学习、回测 |
| **米筐** | 专业、实时、数据全 | 需要付费订阅 | 实盘交易 |
| **FMP** | 美股数据好 | 国内访问不稳定 | 美股交易 |

## 🔧 故障排除

### SDK未安装
```bash
pip install rqdatac
```

### API Key无效
- 检查 `RiceQuantDataProvider.py` 中的API Key
- 联系米筐客服确认账户状态

### 无数据返回
- 检查股票代码格式 (深市.XSHE, 沪市.XSHG)
- 确认日期范围有效
