# 美股周报自动化系统使用说明

## 📋 系统概述

本系统每周一早上自动生成美股分析报告，包含：
1. **CTA技术分析** - 选股排名和买卖信号
2. **财报预期分析** - 财报后的市场预期判断
3. **美联储流动性分析** - 宏观流动性环境
4. **回测验证** - 信号有效性验证

## 🚀 快速开始

### 方法一：自动运行 (推荐)

1. **设置定时任务**
   ```
   双击运行: setup_weekly_task.bat
   ```
   这将创建Windows定时任务，每周一早上8:00自动运行

2. **查看报告**
   - 报告会自动生成在 `Report_YYYY-MM-DD/` 文件夹中
   - 查看 `周报摘要_YYYY-MM-DD.md` 获取核心观点

### 方法二：手动运行

1. **运行今天报告**
   ```
   双击运行: run_manual.bat
   ```

2. **运行指定日期报告**
   ```
   run_manual.bat 2026-02-24
   ```

### 方法三：查看历史报告

```
python view_history.py
```

交互式查看所有历史报告和对比

## ⚙️ 定时任务设置

### 自动设置 (推荐)
1. 右键点击 `setup_weekly_task.bat`
2. 选择"以管理员身份运行"
3. 按提示完成设置

### 手动设置
1. 打开"任务计划程序"
2. 创建基本任务
3. 设置触发器：每周一 8:00
4. 设置操作：启动程序 `python WeeklyAutoReport.py`
5. 起始于：脚本所在目录

### 修改定时任务
```powershell
# 查看任务
schtasks /query /tn "美股周报自动化"

# 删除任务
schtasks /delete /tn "美股周报自动化" /f

# 修改时间 (需要重新创建)
```

## 📊 报告解读

### 1. CTA技术分析 (01_CTA技术分析.xlsx)
- **All_Rankings**: 所有股票排名
- **Strong_Buy**: 强烈看涨股票
- **Sell**: 建议回避股票
- **Tech_Stocks**: 科技巨头分析

### 2. 周报摘要 (周报摘要_YYYY-MM-DD.md)
包含本周：
- 市场概况
- 重点推荐
- 持仓建议
- 风险提示

### 3. 运行日志 (run_log_YYYY-MM-DD.txt)
记录：
- 执行时间
- 模块运行状态
- 错误信息

## 🔧 故障排除

### 问题1: 定时任务不运行
**解决**: 
- 检查Python路径是否正确
- 确认脚本路径无中文和空格
- 查看Windows事件查看器

### 问题2: 数据获取失败
**解决**:
- 检查网络连接
- 确认AkShare库正常
- 查看运行日志

### 问题3: 报告生成不完整
**解决**:
- 检查是否有模块报错
- 查看 `run_log_YYYY-MM-DD.txt`
- 确认所有依赖模块存在

## 📝 自定义配置

### 修改分析参数
编辑 `WeeklyAutoReport.py`:
```python
INITIAL_CAPITAL = 1000000  # 初始资金
POSITION_SIZE = 0.15       # 单股最大仓位
COMMISSION = 0.001         # 手续费
STOP_LOSS = 0.08          # 止损线
```

### 修改运行时间
编辑 `setup_weekly_task.bat`:
```batch
/st 08:00  # 修改为想要的时间
```

### 添加自定义股票
编辑 `Mag7CTAAnalyzer.py` 中的 `CORE_TICKERS` 列表
