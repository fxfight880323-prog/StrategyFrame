## 💡 代码示例

### 获取股票数据

```python
from RiceQuantDataProvider import RiceQuantDataProvider

# 初始化
rq = RiceQuantDataProvider()

# 获取平安银行日线
df = rq.get_stock_price('000001.XSHE', '2024-01-01', '2024-02-01')
print(df.head())
```

### 获取期货数据

```python
# 获取沪深300期货
df = rq.get_future_price('IF2403', '2024-01-01', '2024-02-01')
```

### 获取期权数据

```python
# 获取50ETF期权链
options = rq.get_option_chain('510050.XSHG', '2024-03-27')
```

### 获取指数成分股

```python
# 沪深300成分股
components = rq.get_index_components('000300.XSHG')
print(f"沪深300有 {len(components)} 只成分股")
```

## 🔧 故障排除

### 问题1: ModuleNotFoundError

```
ModuleNotFoundError: No module named 'rqdatac'
```

**解决**:
```bash
pip install rqdatac
```

### 问题2: 连接失败

```
❌ 连接失败: Invalid API Key
```

**解决**:
1. 检查API Key是否正确
2. 确认账户状态正常
3. 联系米筐客服: support@ricequant.com

### 问题3: 无数据返回

```
000001.XSHE: 无数据返回
```

**解决**:
- 检查股票代码格式 (深市.XSHE, 沪市.XSHG)
- 确认日期范围有效
- 检查是否为交易日
