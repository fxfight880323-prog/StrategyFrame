## 📊 核心指标速查

### CTA技术指标
| 指标 | 看多 | 看空 | 权重 |
|------|------|------|------|
| RSI(14) | >50 | <50 | 10分 |
| Momentum(20) | >0 | <0 | 10分 |
| MA Trend Score | 5分 | 0分 | 15分 |
| MACD | >0 | <0 | 10分 |
| Price Position | >60% | <40% | 30分 |

### 财报预期判断
| Surprise | Gap | 判断 | 操作 |
|----------|-----|------|------|
| 超预期(+) | 涨(+) | 合理 | 持有 |
| 超预期(+) | 跌(-) | **过高** | 减仓 |
| 低于预期(-) | 跌(-) | 合理 | 观望 |
| 低于预期(-) | 涨(+) | **过低** | 抄底 |

### 流动性环境
| Net Liquidity | TGA | RRP | 环境 | 股票策略 |
|---------------|-----|-----|------|----------|
| 上升 | 低 | 低 | 宽松 | 超配成长 |
| 下降 | 高 | 低 | 紧缩 | 超配防御 |

## ⚠️ 风险控制清单

### 买入前检查
- [ ] CTA总分 >= 65?
- [ ] 信号为BUY?
- [ ] 排名在前30?
- [ ] 不在SELL列表中?
- [ ] 单股仓位 <= 15%?
- [ ] 整体仓位 <= 90%?

### 卖出检查
- [ ] 信号变为SELL?
- [ ] 亏损超过8% (止损)?
- [ ] 盈利超过20% (止盈)?
- [ ] 排名跌出前50?

### 市场环境检查
- [ ] 流动性不是"全面紧缩"?
- [ ] 美联储没有意外政策?
- [ ] 没有重大地缘政治风险?

## 🎯 常见场景

### 场景1: 选股
```
问题: 本周买什么?

解决:
1. 打开 01_CTA技术分析.xlsx
2. 查看 "Strong_Buy" sheet
3. 选择前10名中你熟悉的股票
4. 检查 "02_财报预期分析" 确认无风险
5. 买入 (仓位10-15%)
```

### 场景2: 调仓
```
问题: 持仓股票排名下降怎么办?

解决:
1. 查看新一周的CTA排名
2. 如果排名从Top10掉到30以后:
   - 考虑减仓50%
3. 如果信号从BUY变SELL:
   - 立即清仓
4. 如果排名维持Top20且信号BUY:
   - 继续持有
```

### 场景3: 避险
```
问题: 市场大跌，如何处理?

解决:
1. 查看 "03_美联储流动性分析"
2. 如果判断为"全面紧缩":
   - 减仓至50%以下
   - 保留现金
3. 如果CTA信号大面积转为SELL:
   - 清仓观望
4. 如果仅是个股下跌:
   - 检查个股止损线
   - 严格执行8%止损
```

| 定时任务不运行 | 电脑关机/权限 | 检查任务计划程序 |
