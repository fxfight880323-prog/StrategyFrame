## 🧮 核心计算公式

### 1. 市场预期波动计算

```python
# 输入数据
stock_price = 100.0       # 当前股价
atm_call = 5.5           # ATM看涨期权价格
atm_put = 5.0            # ATM看跌期权价格

# 计算Straddle
straddle_price = atm_call + atm_put  # 10.5
straddle_pct = straddle_price / stock_price  # 10.5%

# 市场预期波动 (假设正态分布，单方向)
market_expected_move = straddle_pct / 2  # ±5.25%
```

### 2. 交易决策公式

```python
# 判断市场预期是否过高 (卖波动条件)
if iv_rank > 60 and market_expected > user_expected * 1.2:
    strategy = "SELL_VOLATILITY"

# 判断市场预期是否过低 (买波动条件)
if not iv_high and user_expected > market_expected * 1.3:
    strategy = "BUY_VOLATILITY"
```

### 3. 仓位计算公式

```python
# 账户管理
account_size = 100000        # 账户总规模
risk_per_trade = 0.02        # 单笔风险2%
max_position_pct = 0.10      # 最大仓位10%

# 计算
max_risk_amount = account_size * risk_per_trade  # $2,000
max_position = account_size * max_position_pct   # $10,000

# 卖跨式示例
# 收到权利金: $1,000
# 保证金要求: $5,000
# 实际风险: 股价突破盈亏平衡点
```

## 🎯 实战案例

### 案例1: JPM 财报 (适合卖波动)

```
背景:
• 股价: $245
• IV Rank: 65% (偏高)
• ATM Call: $5.50
• ATM Put: $5.20

计算:
Straddle = $5.50 + $5.20 = $10.70
Straddle% = $10.70 / $245 = 4.4%
市场预期波动 = ±2.2%

你的判断:
JPM为传统银行股，财报稳定
实际波动约 ±1.5%

决策:
市场预期(2.2%) > 你的预期(1.5%)
且 IV Rank = 65% > 60%
→ ✅ 卖宽跨式

策略:
• 卖出 $240 Put / $250 Call
• 收取权利金: ~$10
• 盈亏平衡: $230 / $260
• 胜率: 约70%
```

### 案例2: NVDA 财报 (谨慎卖波动)

```
背景:
• 股价: $191.55
• IV Rank: 75% (高)
• ATM Call: $12.50
• ATM Put: $11.80

计算:
Straddle = $24.30
Straddle% = 12.7%
市场预期波动 = ±6.35%

你的判断:
AI业务爆发，可能超预期
实际波动可能 ±8-10%

决策:
市场预期(6.35%) < 你的预期(8-10%)
且 NVDA 为高风险标的
→ ⚠️ 不买也不卖，或小额买跨式

策略:
• 不要卖跨式! 风险极大
• 可考虑小额买宽跨式
• 或等待财报后做方向
```

### 案例3: AAPL 财报 (适中)

```
背景:
• 股价: $266
• IV Rank: 55% (适中)
• ATM Call: $8.20
• ATM Put: $7.80

你的判断:

决策:

• 或卖出更宽的宽跨式 (收集较少权利金但更安全)
```

## ⚠️ 风险控制

### 卖波动风险控制

```
1. 仓位控制
   • 单标的不超过账户10%
   • 总卖波动仓位不超过30%

2. 标的筛选
   • 避开 HIGH_RISK_LIST
   • 优选波动率稳定的标的

3. 止损设置
   • 股价突破盈亏平衡点50%时止损
   • 或权利金损失达到收取金额的200%时止损

4. 时间控制
   • 财报前一天收盘前开仓
   • 财报后第一天开盘即平仓
   • 不要持有过长时间
```

### 买波动风险控制

```
1. 仓位控制
   • 单标的不超过账户5%
   • 买波动为高风险策略，严格控制

2. 时间衰减
   • 尽快在财报后平仓
   • IV崩塌后及时止损

3. 方向判断
   • 买跨式需要大幅波动
   • 买宽跨式需要方向性选择
```
