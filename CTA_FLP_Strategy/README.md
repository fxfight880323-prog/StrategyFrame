# CTA + FLP 策略分析包

## 策略简介

本文件夹包含两套策略的回测分析：

### 1. CTA + FLP 策略（带期权保护）
- **CTA引擎**: 20/60日MA交叉 + 2倍ATR通道突破，波动率倒数加权仓位
- **FLP保护**: 每周五滚动买入SPY Put（Delta -0.07~-0.10），根据VIX动态调整
- **风险平衡**: CTA盈利15%回哺FLP，牛市收缩、熊市增强保护

### 2. CTA 纯策略（无保护）
- **纯趋势跟踪**: 仅CTA信号，无FLP保护
- **仓位配置**: 95% CTA + 5% 现金
- **简化执行**: 无需期权权限
