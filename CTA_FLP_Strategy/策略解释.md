# CTA + FLP 尾部风险对冲策略

## 策略概述

**CTA + FLP** 是一种结合**趋势跟踪（CTA）**和**期权尾部保护（FLP）**的宏观对冲策略，旨在获取趋势收益的同时，通过低成本期权保护对冲极端风险。

> 参考研究：
> - Goldman Sachs Research (2026): Dynamic Hedging in 2026
> - Journal of Derivatives (2025): Fixed Leverage Puts vs Rolling OTM Puts

## 核心组件详解

### 1. CTA趋势引擎 (CTATrendEngine)

**信号生成逻辑：**

| 条件 | 信号 |
|------|------|
| 价格 > 上通道 AND 快MA > 慢MA | 做多 (LONG) |
| 价格 < 下通道 AND 快MA < 慢MA | 做空 (SHORT) |
| 其他情况 | 空仓 (FLAT) |

**参数配置：**
```python
CTA_CONFIG = {
    'fast_ma': 20,           # 快速均线周期
    'slow_ma': 60,           # 慢速均线周期
    'channel_period': 20,    # 通道计算周期
    'channel_width': 2.0,    # ATR通道倍数
    'vol_lookback': 60,      # 波动率回看周期
}
```

**仓位管理 - 波动率倒数加权：**
```
仓位权重 ∝ 1 / 波动率
```
- 低波动环境：增加仓位（趋势稳定）
- 高波动环境：降低仓位（噪音增多）

---

### 2. FLP保护引擎 (FLPEngine)

**FLP (Fixed Leverage Puts)** 是一种系统化的尾部保护策略。

**执行规则：**

| VIX水平 | 保护模式 | 预算调整 | 说明 |
|---------|----------|----------|------|
| VIX < 15 | Long Put | +20% | 保护便宜，多买 |
| 15 ≤ VIX ≤ 30 | Long Put | 正常 | 标准保护 |
| VIX > 30 | Put Spread | -30% | 保护昂贵，降成本 |

**期权选择标准：**
- **标的**：SPY (S&P 500 ETF)
- **到期日**：每周五（7 DTE）
- **Delta**：-0.07 ~ -0.10（轻度价外）
- **行权价**：约2% OTM

**Put Spread 结构（高VIX时）：**
```
买入 Put (Delta -0.10)
卖出 Put (Delta -0.05)  ← 降低权利金成本
```

---

### 3. 风险预算平衡 (RiskBudgetBalancer)

**基础权重配置：**
```python
RISK_CONFIG = {
    'cta_base_weight': 0.80,     # CTA基础权重 80%
    'flp_base_weight': 0.05,     # FLP基础权重 5%
    'cash_weight': 0.15,         # 现金权重 15%
}
```

**动态调整机制：**

1. **盈利回哺机制**
   - CTA产生盈利时，提取15%利润增持FLP保护
   - 形成"赚钱买保险"的正向循环

2. **市场环境适应**
   - **牛市**：CTA权重 × 0.7，释放资金到现金
   - **熊市**：FLP权重 × 1.5（上限10%），增强保护
   - **正常**：维持基础权重

3. **边界约束**
   - FLP权重：2% ~ 10%
   - CTA权重：30% ~ 90%

## 策略优势

### ✅ 优势

1. **非对称收益结构**
   - 趋势行情：CTA获取收益
   - 极端下跌：FLP提供保护
   - 实现"上涨赚钱、下跌有保"

2. **低成本保护**
   - VIX低位时主动增加保护
   - Put Spread在高波动时降成本
   - 年化保护成本约1-3%

3. **系统化执行**
   - 无主观判断，机械执行
   - 每周固定时间建仓
   - 减少情绪干扰

4. **波动率适应**
   - 仓位随波动率自动调整
   - 高波轻仓、低波重仓
   - 适应不同市场环境

### ⚠️ 风险与局限

1. **CTA回撤期**
   - 震荡市CTA可能连续亏损
   - FLP成本持续消耗

2. **保护成本**
   - 长期牛市中FLP持续亏损
   - 类似保险费，需接受小额损失

3. **执行复杂度**
   - 需要期权交易权限
   - 每周需操作期权

4. **黑天鹅局限**
   - 单日期权保护可能滞后
   - 盘前跳空风险
