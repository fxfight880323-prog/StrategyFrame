# 中证A500 技术形态分析与操作推荐系统

## 项目简介

基于**路演PPT技术形态分析框架**，对**中证A500成分股**进行自动化技术形态识别、综合评分和操作推荐。

## 核心功能

1. **技术形态自动识别**
   - 双底形态 (W底)
   - 杯柄形态
   - 头肩底
   - 上升三角形
   - 对称三角形
   - 旗形突破

2. **多维度综合评分** (满分100分)
   - 趋势评分 (25分): 均线排列、价格在均线上方
   - 形态评分 (25分): 经典形态识别与强度
   - 动量评分 (25分): RSI、MACD、近期涨幅
   - 量能评分 (25分): 成交量、量比、量价配合

3. **智能信号生成**
   - 强烈买入 (≥85分)
   - 买入 (70-84分)
   - 偏买入 (55-69分)
   - 中性 (40-54分)
   - 偏卖出/卖出 (<40分)

4. **推荐操作列表**
   - 目标价位
   - 止损价位
   - 盈亏比计算
   - 操作建议

## 使用方法

### 1. 运行分析

```bash
cd PatternStrategy_A500
python A500_Pattern_Analyzer.py
```

### 2. 修改分析范围

编辑 `A500_Pattern_Analyzer.py` 中的 `MAX_STOCKS` 参数：

```python
# 分析全部500只成分股
MAX_STOCKS = None

# 或分析前N只
MAX_STOCKS = 100  # 分析前100只
```

### 3. 输出文件

运行后会生成以下文件（在 `Report_YYYYMMDD/` 目录）：

| 文件 | 说明 |
|------|------|
| `A500_Pattern_Analysis_YYYYMMDD.csv` | 全量分析结果 |
| `A500_Recommendation_List.md` | Markdown格式推荐列表 |
| `A500_Top20_YYYYMMDD.csv` | Top20股票明细 |

## 技术形态识别逻辑

### 1. 双底形态 (W底)

```
识别条件:
1. 两个低点价格相近 (<3%差异)
2. 中间有明显反弹 (>3%)
3. 突破颈线确认

买入时机: 突破颈线后
止损位置: 第二低点下方
```

### 2. 杯柄形态

```
识别条件:
1. U型底部 (跌幅>8%)
2. 右侧回升
3. 柄部整理 (窄幅横盘)
4. 突破柄部高点

买入时机: 突破柄部
目标价位: 杯深度 + 突破点
```

### 3. 头肩底

```
识别条件:
1. 三个谷底，中间最低
2. 左右肩高度相近
3. 突破颈线

买入时机: 突破颈线
目标价位: 头部到颈线的距离
```

### 4. 三角形整理

```
上升三角形:
- 上轨水平，下轨上升
- 突破上轨买入

对称三角形:
- 上轨下降，下轨上升
- 突破方向决定趋势
```
