### 1. 行业中性化 ⏳

**问题**: 
- 米筐`get_industry` API需要特定权限
- 不同行业因子暴露不同（如银行股天然低PE）

**建议实现**:
```python
def industry_neutralize(signals, industries):
    """行业内标准化"""
    result = pd.Series(index=signals.index, dtype=float)
    for industry in industries.unique():
        mask = industries == industry
        ind_signals = signals[mask]
        if len(ind_signals) > 1:
            result[mask] = (ind_signals - ind_signals.mean()) / ind_signals.std()
    return result
```

### 2. 市值中性化 ⏳

**问题**:
- 小盘股通常有更高的价值因子暴露
- 市值因子与价值因子存在共线性

**建议实现**:
```python
def size_neutralize(signals, market_caps):
    """对log(市值)回归取残差"""
    log_cap = np.log(market_caps)
    beta = np.cov(signals, log_cap)[0,1] / np.var(log_cap)
    residual = signals - beta * log_cap
    return (residual - residual.mean()) / residual.std()
```

**当前限制**:
- 米筐`market_cap`因子数据可能不完整
- 需要额外处理缺失值
