# 市值中性与行业中性化错误修复总结

## 🐛 发现的错误

### 1. 股票池获取错误（最严重）

**位置**: `get_stocks()` 函数

**错误代码**:
```python
def get_stocks(self, date: str) -> List[str]:
    try:
        return rq.index_components('000300.XSHG', date).tolist()  # ❌ 错误
    except:
        return []
```

**问题**: 
- `rq.index_components()` 返回的是 Python `list` 对象
- 调用 `.tolist()` 方法会报错（list对象没有此方法）
- 异常被捕获后返回空列表，导致整个回测失败

**修复**:
```python
def get_stocks(self, date: str) -> List[str]:
    try:
        result = rq.index_components('000300.XSHG', date)
        # 兼容不同返回类型
        if isinstance(result, list):
            return result
        elif hasattr(result, 'tolist'):
            return result.tolist()
        else:
            return list(result)
    except Exception as e:
        logger.debug(f"获取股票池失败: {e}")
        return []
```

### 2. 行业分类错误

**位置**: `get_shenwan_industry()` 函数

**错误代码**:
```python
# 使用了错误的API和参数
industry_data = rq.get_industry(stocks, date=trade_date, classification='sws')  # ❌ 错误
```

**问题**:
- `rq.get_industry()` API 不接受 `classification` 参数
- 正确 API 应该是 `rq.get_instrument_industry()` 或 `rq.shenwan_instrument_industry()`

**修复**:
```python
# 方法1: get_instrument_industry (推荐)
industry_data = rq.get_instrument_industry(stocks, source='sws', date=trade_date)
industries = industry_data['first_industry_name']

# 方法2: shenwan_instrument_industry (备选)
industry_data = rq.shenwan_instrument_industry(stocks, date=trade_date)
industries = industry_data['index_name']
```

### 3. 伪行业分类错误

**位置**: 旧版代码 `get_simple_industry()`

**错误**:
```python
def get_simple_industry(self, stocks):
    """简化行业分类：按股票代码前缀"""
    if code.startswith('000'):
        industries[stock] = 'SZ_MAIN'  # 深圳主板
    elif code.startswith('300'):
        industries[stock] = 'SZ_CHIN'  # 创业板
```

**问题**:
- 按股票代码前缀分类（主板/创业板）≠ 真实的行业分类
- 同板块的银行股和科技股被错误分到同一"行业"
- 行业中性化完全失效

**修复**: 使用米筐真实的申万一级行业分类

---

### 4. 价格数据格式处理错误

**位置**: `get_prices()` 函数

**问题**:
- 米筐返回的价格数据有多级索引 `(order_book_id, date)`
- 旧代码没有正确处理这种格式

**修复**:
```python
def get_prices(self, stocks: List[str], start: str, end: str) -> pd.DataFrame:
    prices = rq.get_price(stocks, start, end, frequency='1d', fields=['close'])
    if isinstance(prices, pd.DataFrame) and 'close' in prices.columns:
        prices = prices['close']
        # 关键：unstack将order_book_id转为列
        if prices.index.nlevels > 1:
            prices = prices.unstack(level=0)
        return prices
    return pd.DataFrame()
```

### 5. 数据类型错误

**位置**: `neutralize_factors()` 回归部分

**问题**:
- 行业哑变量是整数类型，但在numpy回归时需要float类型
- 可能导致 `Cannot cast ufunc 'lstsq_n' input` 错误

**修复**:
```python
# 确保数据类型为float
industry_dummies = industry_dummies.astype(float)

# 回归前显式转换
X_np = X.values.astype(float)
y_np = y.values.astype(float)
```

## 🔍 正确的中性化流程

### 1. 获取真实行业数据
```python
industry_data = rq.get_instrument_industry(stocks, source='sws', date=date)
industries = industry_data['first_industry_name']
```

### 2. 构建回归矩阵
```python
# 行业哑变量（剔除一个避免多重共线性）
industry_dummies = pd.get_dummies(industries, prefix='ind')
min_ind = industry_dummies.sum().idxmin()
industry_dummies = industry_dummies.drop(columns=[min_ind])

# 市值因子
X['log_cap'] = np.log(market_caps)

# 合并
X = pd.concat([industry_dummies, X[['log_cap']]], axis=1)
X = sm.add_constant(X)  # 添加截距
```

### 3. 多元回归取残差
```python
# OLS回归
beta = np.linalg.lstsq(X, y, rcond=None)[0]
residual = y - X @ beta

# 标准化
residual = (residual - residual.mean()) / residual.std()
```

### 4. 验证中性化效果
```python
# 各行业均值应接近0
for industry in industries.unique():
    ind_mean = neutralized_signal[industries == industry].mean()
    assert abs(ind_mean) < 1e-6, f"行业{industry}均值不为0"
```

## 💡 使用建议

1. **必须修复**: `get_stocks()` 的 `.tolist()` 问题是最严重的bug，会导致回测完全失效
2. **行业数据**: 使用真实的申万行业分类，而不是代码前缀伪分类
3. **数据类型**: 确保回归前所有数据都是float类型
4. **多重共线性**: 行业哑变量剔除样本最少的行业，避免矩阵奇异
